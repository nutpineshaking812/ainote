浮动弹窗

推荐

聊天窗口以浮动弹窗方式覆盖在页面上方，不占用页面布局空间。Dock 按钮固定于右侧边缘，点击展开员工面板。

// 电商首页、后台管理页等 AiNoteChat.init({ appId: 'your-app-id', apiKey: 'sk-...', container: '#dock-container', chatMode: 'floating', // 浮动模式 });
📋

侧栏嵌入

panel

聊天面板内嵌到页面侧栏区域，与主内容区并列显示。适合知识库、文档编辑、数据分析等需要常驻对话的场景。

// 知识库、文档编辑页 AiNoteChat.init({ appId: 'your-app-id', apiKey: 'sk-...', container: '#dock-container', chatMode: 'panel', chatContainer: '#chat-sidebar', // 侧栏 });
👤

单员工模式

employeeId

只展示指定的一个数字员工。Dock 面板只显示该员工，无需召唤选择，适合固定助理角色的垂直场景。

// 客服助手、法律咨询等 AiNoteChat.init({ appId: 'your-app-id', apiKey: 'sk-...', container: '#dock-container', employeeId: 'emp_cs_001', // 指定单员工 themeColor: '#f59e0b', // 自定义主题色 });
🔌

纯 API 调用

无 UI

不使用 Dock UI，纯编程方式调用数字员工能力。适合后端集成、自定义界面、自动化工作流等场景。

// 完全自定义前端 const api = AiNoteChat.api({ appId, apiKey }); const emps = await api.getEmployees(); await api.sendMessage({ content: '你好', employeeId: emps[0].id, onText: (delta) => console.log(delta), });
